Multi-PDF Smart Searcher - User Guide

🚀 核心功能

這是一款完全在您瀏覽器中運行的 PDF 檢視器與搜尋工具。它允許您同時載入多個 PDF 檔案，並將它們視為一份連續的文件進行全域搜尋與導覽。所有操作都在您的裝置上本地完成，您的檔案絕不會上傳到任何伺服器。

不一定要安裝： 本工具是網頁應用程式，直接用瀏覽器開啟網址即可使用全部功能，不需要安裝。 安裝成 App（PWA）只是多了主畫面圖示與離線開啟的方便，功能完全相同。 已安裝的版本更新後，若畫面沒有變化，請完全關閉 App 再重新開啟一次。

🛠️ 介面與操作

Q1: 如何開始使用？

點擊左上角的 開啟 PDF 按鈕，從您的電腦或行動裝置中選擇您想檢視的 PDF 檔案。您可以按住 Ctrl (Windows) 或 Command ⌘ (Mac) 來一次選擇多個檔案。

Q2: 為什麼有時會出現「還原上次的工作階段」按鈕？

為了提升您的工作效率，本工具具備「記憶上次工作階段」的功能。

  • 首次使用： 當您第一次載入一個或多個 PDF 檔案後，工具會自動將這些檔案的安全副本儲存在您的**個人瀏覽器**中。
  • 再次訪問： 下次您打開此頁面時，應用程式會偵測到這些已儲存的檔案，並在工具列顯示一個 開啟上次檔案 按鈕。這讓您只需一鍵即可還原上次的工作階段，無需重新選擇檔案。
隱私與原理： 此功能由瀏覽器的 IndexedDB 技術驅動。您的檔案副本僅儲存在您的本機裝置上，絕不會上傳到任何線上伺服器。如果您清除此頁面的瀏覽器網站資料，已儲存的檔案也會一併被移除。

Q3: 如何在行動裝置上開關功能選單？

在手機或平板等觸控裝置上，畫面左下角有一顆半透明的 選單 按鈕，點一下即可滑出或收回功能選單（開檔、搜尋、切換檔案）；展開時它會變成 關閉 的叉號。右下角則是 工具，裡面是標記與檢視工具（見 Q8）。您也可以直接點 PDF 內容區域來快速收合選單。

Q4: 如何跨多個 PDF 檔案進行搜尋？

  1. 在搜尋框中輸入您的關鍵字。您可以用空格分隔多個關鍵字，例如：company report，會找出同一頁中依序出現這些詞的地方。
  2. 點擊 搜尋 按鈕。
  3. 搜尋完成後，結果會根據您的裝置以不同方式呈現：
    • 電腦版： 畫面右側會展開搜尋結果面板，列出所有包含關鍵字的頁面，含頁碼、來源檔名與上下文片段。面板寬度可以拖曳分隔線調整，右上角的 列表 / 縮圖 可切換精簡清單與縮圖預覽。
    • 行動裝置版： 畫面底部會滑出結果面板，內容相同。挑定一筆之後面板會收合成一條細長的列，顯示「第 N 頁 · i / 總數」與 上下筆按鈕，方便逐筆看而不遮住頁面。
  4. 點擊任何一個結果即可快速跳轉到該頁面。
進階搜尋提示： 您可以使用正規表示式 (Regular Expressions) 進行更強大的搜尋。只需將您的表達式放在斜線之間，結尾可再加上旗標。例如，/Chapter \d+/i 會進行一個不區分大小寫的搜尋，尋找 "Chapter" 後面跟著一個或多個數字的內容。

一般搜尋不必擔心這件事：只有「以 / 開頭、且結尾那段確實是合法旗標」的輸入才會被當成正規表示式。所以像 /usr/bin、/2026/09、/合約/附件 這種路徑或日期，都會照字面比對，不會被誤判。

Q5: 如何導覽頁面與搜尋結果？

  • 使用 上一頁 / 下一頁 按鈕逐頁翻閱； 第一頁 可直接回到第一頁。手機與橫向畫面上，頁面左右兩側也各有一顆半透明箭頭可以翻頁。
  • 拖曳頁碼旁邊的**滑桿**進行快速跳頁。
  • 在輸入框中輸入頁碼並點擊 前往 按鈕，可直接跳轉到指定的全域頁碼。
  • 在搜尋模式下，點擊右側面板中的縮圖或下拉選單中的項目，可直接跳到該搜尋結果。
  • (推薦) 在觸控裝置上，直接在 PDF 上**左右滑動**即可翻頁或跳至上/下一個搜尋結果。

Q6: 如何調整頁面顯示比例？

在頂部工具列（電腦版）或滑出選單中（行動裝置版），您可以使用縮放控制項：

  • 高度：(預設模式) 讓頁面高度符合檢視器的高度，適合垂直閱讀。
  • 寬度：讓頁面寬度符合檢視器的寬度。
  • / ：手動放大或縮小頁面，中間顯示目前的百分比。

📱 行動裝置體驗

Q7: 滑動手勢有什麼特殊功能？

滑動手勢是為了提升在行動裝置上的瀏覽效率而設計的：

  • 一般模式： 當您未進行搜尋時，左右滑動會切換至上一頁或下一頁。
  • 搜尋模式： 當您執行搜尋後，左右滑動會直接跳轉到包含**上一個或下一個搜尋結果**的頁面，讓您能快速瀏覽所有匹配項。
  • 逐筆瀏覽是環狀的：最後一筆再往下會回到第一筆。目前位置隨時顯示在結果列的「i / 總數」上。
  • 上下筆、方向鍵與滑動都會遵守檔案篩選：篩到單一檔案時，只會在該檔的結果之間移動。
  • 注意：為避免操作衝突，當螢光筆、文字選取、段落選取或放大鏡工具啟用時，滑動導覽功能會暫時停用。

🎨 標記與檢視功能（右下角 工具）

Q8: 「工具」裡有哪些功能？

點右下角的 工具 會展開一組快速動作按鈕，依用途分成四組：

分享與截圖

  • 分享 PDF：將當前頁面（含標記）以圖片形式分享到其他應用程式，需瀏覽器支援。
  • 分享本站連結：分享這個工具本身的網址，並帶上參數讓 LINE 改用預設瀏覽器開啟。

顯示

  • 符合寬度：讓頁面寬度填滿檢視器。
  • 符合高度：讓頁面高度填滿檢視器（預設）。

文字工具

  • 切換搜尋底線：覺得搜尋結果的波浪底線干擾時，點此暫時隱藏，再點一次恢復。
  • 螢光筆標記選擇內容：在 PDF 上自由繪製，就像使用真的螢光筆。
  • 清除本頁標記：清除當前頁面上所有的螢光筆標記。

選取與筆記

  • 選擇文字：預設關閉文字選取以利縮放與滑動手勢；點此讓 PDF 內容變為可選取，再點一次關閉。
  • 選擇段落：啟用後在頁面上點一下，即自動選取整個段落並顯示複製按鈕。
  • 複製選擇內容：把選取到的文字複製到剪貼簿。
  • 所有分頁筆記：列出目前已載入檔案的所有筆記，點一則即可跳到該頁。
  • 放大鏡：啟用後移動滑鼠（電腦）或拖曳手指（行動裝置）即可看到即時放大畫面。
  • 新增筆記：點 PDF 任一處放置筆記。
手機版比較精簡： 螢幕較窄時只留下最常用的幾顆（分享、符合寬度／高度、螢光筆、清除標記、放大鏡）；切換底線、選字、選段、複製、筆記等按鈕在電腦版才會出現。

Q9: 如何調整放大鏡的縮放等級？

當放大鏡工具啟用時，畫面上會出現一個「縮放」下拉選單。您可以選擇 1.5x 到 3.5x 的放大倍率。
