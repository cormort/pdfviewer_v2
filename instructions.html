Multi-PDF Smart Searcher - User Guide

🚀 核心功能

這是一款完全在您瀏覽器中運行的 PDF 檢視器與搜尋工具。它允許您同時載入多個 PDF 檔案，並將它們視為一份連續的文件進行全域搜尋與導覽。所有操作都在您的裝置上本地完成，您的檔案絕不會上傳到任何伺服器。

🛠️ 介面與操作

Q1: 如何開始使用？

點擊左上角的 選擇檔案 按鈕，從您的電腦或行動裝置中選擇您想檢視的 PDF 檔案。您可以按住 Ctrl (Windows) 或 Command ⌘ (Mac) 來一次選擇多個檔案。

Q2: 為什麼有時會出現「還原上次的工作階段」按鈕？

為了提升您的工作效率，本工具具備「記憶上次工作階段」的功能。

  • 首次使用： 當您第一次載入一個或多個 PDF 檔案後，工具會自動將這些檔案的安全副本儲存在您的**個人瀏覽器**中。
  • 再次訪問： 下次您打開此頁面時，應用程式會偵測到這些已儲存的檔案，並顯示一個綠色的 Restore Last Session 按鈕。這讓您只需一鍵即可還原上次的工作階段，無需重新選擇檔案。
隱私與原理： 此功能由瀏覽器的 IndexedDB 技術驅動。您的檔案副本僅儲存在您的本機裝置上，絕不會上傳到任何線上伺服器。如果您清除此頁面的瀏覽器網站資料，已儲存的檔案也會一併被移除。

Q3: 如何在行動裝置上開關功能選單？

在手機或平板等觸控裝置上，您會在左側看到一個橘色的箭頭把手 ›。點擊此把手可以滑出或收回功能選單。您也可以透過點擊右側的 PDF 內容區域來快速收合選單。

Q4: 如何跨多個 PDF 檔案進行搜尋？

  1. 在「Keyword or Regex」輸入框中輸入您的關鍵字。您可以用空格分隔多個關鍵字，例如：company report。
  2. 點擊 Search 按鈕。
  3. 搜尋完成後，結果會根據您的裝置以不同方式呈現：
    • 電腦版： 畫面右側會出現一個「Bookmarks / Search Results」面板。此面板會顯示所有包含關鍵字的頁面縮圖、頁碼與上下文預覽，就像一組為此次搜尋建立的臨時書籤。
    • 行動裝置版： 畫面底部會出現一個「Search Results」下拉選單，列出所有符合的頁面。
  4. 點擊任何一個結果即可快速跳轉到該頁面。
進階搜尋提示： 您可以使用正規表示式 (Regular Expressions) 進行更強大的搜尋。只需將您的表達式放在斜線之間。例如，/Chapter \d+/i 會進行一個不區分大小寫的搜尋，尋找 "Chapter" 後面跟著一個或多個數字的內容。

Q5: 如何導覽頁面與搜尋結果？

  • 使用 Prev / Next 按鈕逐頁翻閱。
  • 拖曳頁碼旁邊的**滑桿**進行快速跳頁。
  • 在輸入框中輸入頁碼並點擊 Go 按鈕，可直接跳轉到指定的全域頁碼。
  • 在搜尋模式下，點擊右側面板中的縮圖或下拉選單中的項目，可直接跳到該搜尋結果。
  • (推薦) 在觸控裝置上，直接在 PDF 上**左右滑動**即可翻頁或跳至上/下一個搜尋結果。

Q6: 如何調整頁面顯示比例？

在頂部工具列（電腦版）或滑出選單中（行動裝置版），您可以使用縮放控制項：

  • Fit Height: (預設模式) 讓頁面高度符合檢視器的高度，適合垂直閱讀。
  • Fit Width: 讓頁面寬度符合檢視器的寬度。
  • + / -: 手動放大或縮小頁面。

📱 行動裝置體驗

Q7: 滑動手勢有什麼特殊功能？

滑動手勢是為了提升在行動裝置上的瀏覽效率而設計的：

  • 一般模式： 當您未進行搜尋時，左右滑動會切換至上一頁或下一頁。
  • 搜尋模式： 當您執行搜尋後，左右滑動會直接跳轉到包含**上一個或下一個搜尋結果**的頁面，讓您能快速瀏覽所有匹配項。
  • 當您到達第一個或最後一個搜尋結果時，會顯示短暫的提示訊息。
  • 注意：為避免操作衝突，當螢光筆、文字選取、段落選取或放大鏡工具啟用時，滑動導覽功能會暫時停用。

🎨 標記與檢視功能 (右下角浮動按鈕)

Q8: 右下角的按鈕有哪些功能？

這是一組快速動作按鈕，讓您在閱讀時方便使用各種工具。

  • S: 切換搜尋底線。如果您覺得搜尋結果的波浪底線很干擾，點此按鈕可暫時隱藏它們。再點一次即可恢復顯示。
  • ¶: 啟用段落選取。啟用後，只需在 PDF 頁面上點擊一下，工具就會自動選取您點擊所在的整個段落，並顯示一個「Copy」按鈕供您快速複製。
  • 📝: 複製整頁文字。點擊此按鈕可將當前頁面的所有文字複製到剪貼簿。
  • TS: 啟用文字選取。預設情況下，文字選取是關閉的，以利於更流暢的縮放與滑動手勢。點擊此按鈕可讓 PDF 內容變為可選取狀態，方便您複製特定文字。再點一次即可關閉。
  • 🖌️: 啟用螢光筆。點擊後，您可以在 PDF 頁面上自由繪製，就像使用真的螢光筆一樣。
  • 🗑️: 清除螢光筆。清除當前頁面上所有的螢光筆標記。
  • 🔍: 切換放大鏡。啟用後，移動滑鼠（電腦）或拖曳手指（行動裝置）即可看到即時的放大畫面。
  • 📷: 匯出為圖片。將包含您螢光筆標記的當前頁面，匯出為 PNG 圖片並下載。
  • 🔗: 分享頁面。如果您的瀏覽器支援，這可以讓您將當前頁面（含標記）以圖片形式分享到其他應用程式。

Q9: 如何調整放大鏡的縮放等級？

當放大鏡工具 🔍 啟用時，功能選單中會出現「Magnifier Zoom」選項。您可以選擇 1.5x 到 3.5x 的縮放等級。
